# Findings (as-built notes)

This file is NOT a spec — it doesn't define a contract. It's a dated
log of what exploration tasks actually found in the codebase, used to
resolve TBDs in `system.md`'s contract table and to catch drift
between what a spec assumes and what the code currently does.

Each entry: date, what was explored, what was found, which contract
row(s) it resolves. When a finding resolves a TBD, go update the
actual row in `system.md` / `controller.md` / `allocation.md` — this
file is the evidence trail, not a substitute for the contract living
in the spec.
